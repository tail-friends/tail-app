# 확인 필요 항목

원본 Notion 문서에는 현재 환경에서 접근하지 못했다. 아래 항목은 임의로
결정하지 않고 기획·플랫폼 담당자와 확인한다.

- Android 최종 application ID: 초기 프로젝트는 `com.tailfriends.tail_friends`를 사용 중이며 Play 등록 전에 확정 필요
- 앱 표시명, 아이콘, 브랜드 색상과 지원 언어
- 최소/대상 Android 버전의 제품 정책
- 개발·스테이징·운영 API 주소와 인증 계약
- 상태 관리, 내비게이션, 네트워크, 로컬 저장소 기술 선택
- F-25 쿨링 모드의 최초 출시 포함 여부와 급여 상태 처리
- MVP/확장 기능 간 우선순위 충돌
- 종별 건강 경고 기준과 안내 문구의 검토 주체
- 사진 원본 보관 기간, 동의 철회 및 삭제 정책
- 캐릭터 이미지 분석·생성 서비스 계약과 오류 처리
- Android 릴리스 서명키 소유·보관·복구 절차
